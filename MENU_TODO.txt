---------------------------------------------------------------------
 D. RAPPELS UTILES
---------------------------------------------------------------------

 - Un widget enfant previent son parent avec un Event Dispatcher
   (OnBack, OnSelected...). Le parent (WBP_MainMenu) decide quelle
   page afficher via Set Active Widget Index sur WS_Menu.
 - Avant de coller des noeuds : creer d'abord les variables et
   dispatchers (avec leurs parametres), sinon les noeuds arrivent casses.
 - Ctrl+A / Suppr : bien verifier qu'on est dans l'onglet Graph et
   pas Designer.
 - Debug : Print String juste avant l'endroit qui casse ; les messages
   vont aussi dans Saved/Logs/FirePersonneShooter.log
 - Struct / map : Soft World Reference (pas Object Reference, sinon
   toute la map est chargee en memoire avec la Data Table).
 - Texte UMG blanc par defaut : attention aux fonds clairs.
